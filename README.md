# ⚡ SmartCharge AI

An AI-powered EV charging platform for finding stations, booking slots and monitoring chargers in real time.

🔗 **Live site:** https://mansoorx1.github.io/SmartCharge-AI/

> 🚧 **Status:** Work in progress. This is our final year project, and features are still being added.

## Features
- 🤖 **AI-based prediction:** forecasts charging demand and suggests good charging periods
- 📅 **Smart slot booking:** reserve a time and avoid clashes with walk-in users
- 🔌 **Real-time charger status:** see whether a charger is available, booked or occupied
- ⚡ **Smart load management:** uses predicted demand to help optimise charging schedules
- 📍 **Station finder:** browse nearby charging stations and their chargers
